# Anannya Upasana — Academic Website

This is a plain HTML/CSS academic website designed for GitHub Pages.

## Files
- `index.html` — the full website content
- `style.css` — layout and visual styling
- `Anannya_Upasana_CV.pdf` — downloadable CV

## Publish on GitHub Pages
Place these three files in the root of the `AnannyaU.github.io` repository.

The website will then be available at:
https://anannyau.github.io/

No build process, framework, or package installation is required.
